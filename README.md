# FinTech Mobile Banking & Wallet App

A modern, high-density dark-mode mobile banking prototype built with React, Tailwind CSS, and Chart.js. Engineered using Flexbox auto-layout principles, this application delivers an authentic mobile wallet user interface wrapped inside a responsive device frame.

### 🚀 Key Features
*  **Biometric Authentication:** Simulated fingerprint unlock screen with custom visual pulse animations.
*  **Budget Spending Breakdown:** Interactive financial metrics and category allocation graphs powered by `react-chartjs-2`.
*  **Send & Request Money Flows:** Multi-step wizard allowing users to search contacts, input custom amounts, and dispatch transactions or payment requests.
*  **Virtual Card Management:** Interactive credit/debit card gallery with real-time dynamic card issuance and toggle settings.
*  **User Profile & Security:** Settings portal with account metrics and secure biometric session logout.
*  **Mobile Device Wrapper:** Rendered inside a sleek iOS frame with custom bottom navigation for an authentic mobile app preview.

### 🛠️ Tech Stack
* **Framework:** React 18 (Vite)
* **Styling:** Tailwind CSS (Auto Layout / Flexbox Design System)
* **Icons:** Lucide React
* **Data Visualization:** Chart.js & `react-chartjs-2`
* **Language:** JavaScript (ES6+)
